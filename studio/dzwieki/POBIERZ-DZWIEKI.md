# Jak pobrać pliki audio

Dźwięki pochodzą z **Pixabay** (licencja Content License — darmowe, do użytku komercyjnego, bez podawania źródła).

Pobrane pliki MP3 wrzuć do folderu: `studio/dzwieki/pliki/`

## Kroki

1. Wejdź na https://pixabay.com/sound-effects/
2. Wyszukaj frazę z tabeli (wybierz najlepiej pasujący dźwięk)
3. Pobierz MP3
4. Zmień nazwę pliku na tę z kolumny „Zapisz jako"
5. Wrzuć do `studio/dzwieki/pliki/`
6. Powtórz dla wszystkich 19 dźwięków
7. `git add . && git commit -m "Dodano pliki audio" && git push`

Po pushu kursantki dostają dźwięki przy następnej aktualizacji pluginu.
