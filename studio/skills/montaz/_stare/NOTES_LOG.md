# Dziennik uwag i przepisanych reguł

Każda uwaga kursantki trafia tutaj jako jedna linia — po tym jak reguła w `rules/*.md` została przepisana.

## Format

```
DATA | UWAGA KURSANTKI | PLIK I LINIA | NOWE BRZMIENIE
```

## Jak działa system

Po każdej uwadze od kursantki:

1. Napraw w tym filmie.
2. Zapytaj: „Która reguła, gdyby istniała, zapobiegłaby temu?"
3. Znajdź ją w `rules/*.md` i **przepisz** — nie dodawaj nowej obok. Jeśli dwie reguły mówią to samo, scal je. Stare brzmienie znika.
4. Dopisz jedną linię poniżej: data | uwaga | który plik przepisałaś | nowe brzmienie.
5. Zrób nowy draft i sprawdź.
